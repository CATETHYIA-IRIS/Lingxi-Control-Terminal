灵汐 Remote

GitHub Pages 远程控制台 · V6.0.5

先连接巴法云，
再进入远程中控。

远程端只负责轻量状态查看、设备控制、场景切换和日志展示。本地 ESP32 WebUI 继续负责完整语音、ASR、TTS、SD 角色资源和工程化诊断。

MQTT通过巴法云 WebSocket 与家中中控通信，不访问 192.168.4.1。
Safe不在源码写死密钥；参数只保存到当前浏览器 localStorage。
Light保留灵汐本地 UI 风格，但去掉远程端无法读取的 SD 头像与立绘。

连接灵汐中控

填写巴法云 MQTT WebSocket 参数。推荐正式环境使用 AppID / SecretKey；测试时可用私钥 UID 作为 ClientID。

不要把真实 UID、AppID、SecretKey 提交到 GitHub。勾选“记住配置”时，配置只保存到当前浏览器，不会上传到仓库。

连接成功后会自动订阅状态主题和日志主题，并向命令主题发送 cloud_report 请求中控上报。
